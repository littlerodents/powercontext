# 高德赛题资产：周边去哪儿（地点推荐助手 Skill）

## 提交物

本题唯一提交产物是 **`gaode/SKILL.md`**（题面："提交产物：一个 Skill 文件（SKILL.md）"）。
`examples/validation-cases.md` 为随附验证样例（评审参照题面 3.1 的评测场景自检用），不是必交物。

## 工作原理（与题面一致）

- 评测时由**平台统一提供 Agent 运行环境、模型和高德 MCP 工具配置**，加载本 Skill 执行单轮任务，不做源码测试。
- Skill 引导 Agent 使用高德 MCP Server 的两项能力：**地点搜索**（按起点与需求查附近 POI）与**步行路线规划**（起点→POI 的真实步行距离/耗时）。
- 输出最多 3 个独立备选，含名称/地址/步行距离/时间/推荐理由；不足、异常、未核实信息均如实标注，不编造。
- 长期记忆、PowerMem、seekdb 接入均非必做项（题面明确），本 Skill 不引入。

## 提测与验证

在评测平台填写本仓库、提交分支及完整 commit SHA。代码保留官方 `2026-competition-ecosystem` 基线历史。

本地核对了 Skill 元数据和普通推荐、时间限制、排序偏好、结果不足、查询异常五类分支。样例记录预期行为；地点、路线和最终得分以平台真实高德工具调用和官方提测记录为准。
