# OceanBase 简介

OceanBase 是蚂蚁集团自主研发的企业级分布式关系数据库。它具备强一致性、高可用性、高性能和可扩展性等核心特性。

## 架构特点

OceanBase 采用 Shared-Nothing 架构，由多个 Zone 组成。每个 Zone 包含多个 OBServer 节点，数据在多个 Zone 之间进行多副本同步。

### 多副本机制

OceanBase 默认采用三副本策略，基于 Paxos 协议保证数据一致性。当少数副本发生故障时，系统可以自动选举新的主副本，实现故障自愈。

### 分布式事务

OceanBase 支持分布式事务，采用两阶段提交（2PC）协议保证跨分区事务的原子性和一致性。同时通过并行提交和批量处理优化事务性能。

## 存储引擎

OceanBase 的存储引擎基于 LSM-Tree 设计：

- **MemTable**：内存中的可变数据结构，用于接收写入操作
- **SSTable**：磁盘上的不可变数据结构，定期从 MemTable 压缩生成
- **BloomFilter**：用于快速判断数据是否存在于某个 SSTable 中

## SQL 引擎

OceanBase 兼容 MySQL 和 Oracle 两种模式，支持大部分标准 SQL 语法。SQL 引擎包含：

- 解析器：将 SQL 文本解析为语法树
- 优化器：基于代价的查询优化（CBO）
- 执行器：分布式执行计划引擎

## 高可用

OceanBase 通过以下机制保证高可用：

- 自动故障检测和恢复
- 无损 zone 升级
- 跨地域容灾部署
- 数据备份与恢复

## 应用场景

OceanBase 广泛应用于金融、电商、政务等领域，典型场景包括：

- 核心交易系统
- 实时风控
- 海量数据分析
- 多活容灾
